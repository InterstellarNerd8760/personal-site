# Development roadmap

This sequence tracks experimental evidence and decisions needed for a possible physical archive. The [edition definitions](archive-editions.md) set logical targets. The [engineering validation plan](engineering-validation-plan.md) tracks the evidence needed to advance.

| Milestone | Deliverable | Acceptance gate |
| --- | --- | --- |
| 1. Credible mission proposal | Centauri Core baseline, optional Centauri Extended, public project material and an engineering questionnaire | Review mission citations, provisional budgets, scope and status before considering any external submission |
| 2. Functional encoding prototype | Progressive mathematical primer, photographic raw rasters, specification, test vectors and independent decoder | Reproduce fixed vectors and source-derived previews. Run a blind interpretation study using held-out examples and report ambiguous and incorrect responses |
| 3. Recoverable archive | Tested error correction, record integrity, simulations and archive-level redundancy | Recover inside declared bounds. Report missing and damaged records explicitly. Reproduce tests for metadata, correction-symbol and mixed-copy loss |
| 4. Scientific knowledge collection | Reviewed foundations, a visual vocabulary and expanded coverage of life, human anatomy, physical science, history, technology and culture | Log source checks and human review per revision. Resolve image provenance, permissions and coverage gaps. Work toward 150–250 selective articles across editorial passes |
| 5. Physical demonstrator | Manufactured coupon, etched or otherwise observable primer, protected sample frames and measured readout | Record feature geometry, contrast, registration, readout resolution and pre/post-exposure recovery. Repeat interpretation trials using the fabricated sample |
| 6. Mission feasibility and qualification | Verified interfaces and environments, candidate carrier, mass/volume accounting, materials and test plan | Obtain mission-provided constraints, evaluate structural and environmental risks, and agree qualification and integration gates |
| Optional. Centauri Extended | Wikipedia-derived text corpus, additional scientific and cultural records and a dense archive | Verify an explicitly pinned snapshot and attributed derivative. Measure storage, qualify an independent bootstrap and evaluate feasibility separately |

The repository contains the development transport, curated photographs, proposal and software experiments supporting milestones 1–4. Article status is tracked individually. Blind trials, carrier fabrication, environmental testing and spacecraft qualification remain open.
