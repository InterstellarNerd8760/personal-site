02 / How it works

        
One checkpoint. Many machines.

        

          
01Assign
Common model and distinct data shards.

          
02Train
Independent, bounded runs on authorized compute.

          
03Validate
Check metadata, weights and held-out loss.

          
04Advance
Aggregate reviewed updates and evaluate.

        

        
GitHub coordinates code and research. Discord is for discussion. Hugging Face is intended for reviewed model and dataset artifacts. See the architecture for technical details.

05 / About

        
Open research, built from scratch.

        
Bloom's name was inspired by the Anti-Doomer community. This independent project is not affiliated with that community or BigScience BLOOM. Original code and documentation are Apache 2.0; official model releases target the Open Source AI Definition 1.0 after review.
