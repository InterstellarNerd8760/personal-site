From a prototype to a shared model.

Implemented Architecture, byte tokenizer, reproducible text data and checkpoint validation.

In review Persistent training and the contributor notebook. First 100-step CPU run completed; weights saved. Training results · PR #13

05 / About

Open research, built from scratch.

Bloom's name was inspired by the Anti-Doomer community. This independent project is not affiliated with that community or BigScience BLOOM. Original code and documentation are Apache 2.0; official model releases target the Open Source AI Definition 1.0 after review.
