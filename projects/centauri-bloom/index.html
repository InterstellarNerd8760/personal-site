Training / Contribute compute

Train the model.

One trainer, one model, multiple datasets. Choose your dataset and training budget in Google Colab. Every run starts from the latest accepted checkpoint and automatically submits a candidate Hugging Face pull request.

Bloom Trainer

Default: Jaron’s instruction dataset · 3,000 steps. Switch to FineWeb-Edu, TinyStories, Cosmopedia, public-domain literature or a mixed recipe using the dataset selector.

Open trainer ↗Training guide ↗

Choose a GPU, confirm data permission, authorize, train, and review the submitted PR before merging.

Upload recovery

05 / About

Open research, built from scratch.

Bloom's name was inspired by the Anti-Doomer community. This independent project is not affiliated with that community or BigScience BLOOM. Original code and documentation are Apache 2.0; official model releases target the Open Source AI Definition 1.0 after review.
