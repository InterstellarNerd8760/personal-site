Centauri Archive

In development · Software · Edition 0.6.1

Centauri Archive is an independent, open-source prototype for a compact record of Earth, life, and human civilization. The long-term idea is a contribution to an interstellar mission; the initial proposed context is Fermi Explorer. There is no affiliation, flight approval, payload allocation, or integration agreement.

What exists today is a digital development package and a public reading site: an encyclopedia of introductory drafts, an editorial photo atlas, and an 8×8 binary decoding lab. The work is honest about what has not been demonstrated yet, including independent decoding, radiation survival, and a physical carrier.

Behind the project

A record, still being proven.

The public site now lives on this domain at /archive/, so the encyclopedia, photographs, and decoding experiments can be read next to the rest of my work. The development ZIP stays in the source repository; this site publishes the pages, records, and manifest, not the packaged payload.

Working today

A readable collection

Introductory records, credited photographs, a versioned manifest, and a human-readable encyclopedia and image library.

Active research

A decoding primer

The 8×8 lab shows how reading order changes an image. It does not show that an unfamiliar reader could discover those rules alone.

Not yet built

A spacecraft-ready artifact

No flight hardware, approved payload, or independently validated physical format exists yet.
