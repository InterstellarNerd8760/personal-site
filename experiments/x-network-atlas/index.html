How to read this

An honest map starts with honest data.

Demo mode uses fictional examples so you can explore the interface. Nothing about the demonstration represents my actual followers, interactions, or communities.

Archive mode uses only files you explicitly select. X archives typically list followers/following by account ID, so some nodes display numeric identifiers until post mentions provide handles. A mention represents an outgoing mention in the imported posts, not a measured conversation or endorsement.

Privacy and scope: processing and saved state run in your browser's local storage. No archive data is uploaded or published by this tool. Clear data to remove the local copy; browser storage may also be cleared automatically. This is a first-degree network, not a complete X social graph.
