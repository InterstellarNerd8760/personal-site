05 / Field notes

The work between milestones.

ProductAccuracy is a feature.

For a study app, a beautiful interface can't make up for a wrong answer key. The useful work is checking every question against the official pool.

HardwareA sensor reading only matters if you can trust it.

WALL-E is a chain of small systems: sensors, timestamps, storage, power. The next milestone isn't a new feature. It's a repeatable bench test that proves the chain works.

MethodBuild the smallest thing that proves the idea.

When a project feels huge, isolate the part I'm least sure of, test just that, write down what happened, then decide what's next.
